APPLY TO YOUR EXISTING CURSOR PROJECT
1. Extract this ZIP using Windows Extract All.
2. Make a backup copy of your existing project folder.
3. Open the extracted kisetsu-expressions-main folder.
4. Copy its src and public folders together.
5. Paste them inside your existing project folder, beside package.json.
6. Choose Replace for matching files. Merge folders if Windows asks.
   This keeps your existing Git repository and environment configuration.
7. In Cursor, open your existing project folder.
8. In Terminal run: npm run dev
9. Open the localhost address printed in the terminal.

No package.json or dependency changes are required. If this is a fresh
checkout without installed dependencies, run npm install first.
